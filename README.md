# 🛡️ Shield — Ultimate VPS Setup

Комплексный Bash-скрипт для автоматической настройки безопасного сервера, развертывания VPN (3X-UI) и блокировщика рекламы (AdGuard Home).

[![Bash](https://img.shields.io/badge/language-bash-black.svg)](https://www.gnu.org/software/bash/)
[![Docker](https://img.shields.io/badge/docker-ready-blue.svg)](https://www.docker.com/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

**Особенности:**
- 🚀 **Быстрый старт:** Полная настройка чистого VPS за 3-5 минут
- 🛡️ **Hardening:** Продвинутая защита (Fail2Ban, UFW, Auditd, Secure SSH)
- 🐳 **Docker Stack:** Автоматическое развертывание 3X-UI и AdGuard Home
- ⚡ **Оптимизация:** Тюнинг ядра Linux (BBR, Sysctl) для лучшей скорости сети
- 🔄 **Безопасность:** Система автоматического отката (Rollback) при ошибках

## Возможности

### 🛠 Системная настройка (Hardening):
- 👤 Создание sudo-пользователя и отключение root-доступа
- 🔑 Смена SSH порта и настройка ключей
- 🧱 Настройка Firewall (UFW) по принципу "запрещено всё, кроме разрешенного"
- 🕵️‍♂️ Установка и настройка Auditd и Fail2Ban
- 🚀 Включение алгоритма TCP BBR для ускорения сети

### 📦 Приложения (Docker):
- 🌐 **3X-UI Panel:** Управление VPN протоколами (VLESS, VMess, Reality)
- 🛑 **AdGuard Home:** Локальный DNS-сервер с блокировкой рекламы и трекеров
- 🤖 **Telegram Bot:** Заготовка контейнера для вашего Python-бота

## Технологический стек

- **Bash** - основная логика автоматизации
- **Docker & Docker Compose** - оркестрация контейнеров
- **UFW & Fail2Ban** - сетевая безопасность
- **Ubuntu/Debian** - поддерживаемые ОС

## Структура проекта

Скрипт создает следующую структуру на сервере в папке `/root/myserver`:

~~~text
/root/myserver/
├── docker-compose.yml    # Основной файл конфигурации сервисов
├── xui/                  # Данные панели 3X-UI
│   ├── db/
│   └── log/
├── adguard/              # Данные AdGuard Home
│   ├── work/
│   └── conf/
└── bot/                  # Папка для вашего Telegram бота
    ├── Dockerfile
    ├── main.py
    └── requirements.txt
~~~

## 🚀 Быстрый старт

### Требования:
1. Чистый VPS с **Ubuntu 20.04+** или **Debian 11+**
2. Права **root**

### Установка:

~~~bash
# 1. Клонируйте репозиторий
git clone [https://github.com/imcrazymonk-pixel/shield.git](https://github.com/imcrazymonk-pixel/shield.git)

# 2. Перейдите в папку
cd shield

# 3. Дайте права на выполнение
chmod +x Shield.sh

# 4. Запустите
./Shield.sh
~~~

## Процесс установки

Скрипт интерактивный и задаст несколько вопросов:

1. **Имя хоста (Hostname):** Как будет называться сервер.
2. **Таймзона:** Часовой пояс сервера (по умолчанию Moscow).
3. **Новый пользователь:** Имя и пароль для безопасного входа (вместо root).
4. **SSH порт:** Нестандартный порт для защиты от сканеров (например, 2222).

После ввода данных начнется автоматическая настройка. 🪄

## Использование после установки

После успешного завершения скрипт выведет сводную таблицу. Сохраните эти данные!

### 🔌 Доступ к сервисам:

| Сервис | Адрес | Логин / Пароль (Default) |
| :--- | :--- | :--- |
| **3X-UI (VPN)** | `http://IP-SERVER:2053` | `admin` / `admin` |
| **AdGuard Home** | `http://IP-SERVER:3000` | Настраивается при первом входе |
| **SSH** | `IP-SERVER:ВАШ_ПОРТ` | Ваш новый пользователь |

### 👤 Управление сервером

Для управления контейнерами используйте стандартные команды Docker Compose из папки проекта:

~~~bash
# Переход в рабочую директорию
cd /root/myserver

# Просмотр статуса контейнеров
docker compose ps

# Просмотр логов (например, для xui)
docker compose logs -f xui

# Перезапуск всех сервисов
docker compose restart
~~~

## Устранение неполадок

### Не могу подключиться по SSH
- Убедитесь, что вы используете **новый порт**, который указали при установке.
- Входите под **новым пользователем**, root доступ по SSH отключен скриптом.
- Пример: `ssh username@ip-address -p 2222`

### AdGuard пишет, что 53 порт занят
Скрипт автоматически освобождает 53 порт от `systemd-resolved`. Если проблема осталась, проверьте, не запущены ли другие DNS сервисы:
~~~bash
sudo lsof -i :53
~~~

### Как обновить 3X-UI или AdGuard?
Просто обновите образы Docker:
~~~bash
cd /root/myserver
docker compose pull
docker compose up -d
~~~
